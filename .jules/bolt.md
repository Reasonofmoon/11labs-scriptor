## 2024-05-24 - HTML5 Canvas & Web Audio API Optimization in React
**Learning:** In React components using HTML5 Canvas with Web Audio API (like `Visualizer.tsx`), creating `LinearGradient` objects inside the `requestAnimationFrame` loop creates severe memory pressure and performance bottlenecks. Furthermore, `Math.random()` used for visual idle states causes Next.js hydration mismatches. Web Audio API frequency data bounded between 0-255 allows for perfect array-based caching.
**Action:** When animating canvas based on bounded byte data, pre-calculate expensive rendering objects (like gradients) into an array cache initialized *outside* the `requestAnimationFrame` loop. Add early termination conditions (`if (x > canvas.width) break;`) to drawing loops to avoid rendering off-screen. Replace `Math.random()` with deterministic constant arrays for idle UI states to avoid hydration mismatches.
