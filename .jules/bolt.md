## 2024-05-28 - Canvas Animation and Web Audio Optimization
**Learning:** For HTML5 Canvas animations in React `useEffect`, creating objects (like `LinearGradient`) repeatedly inside the render loop causes significant garbage collection overhead. Since the Web Audio API populates `Uint8Array` with bounded integers (0-255), we can exactly pre-calculate and cache corresponding rendering objects. Additionally, Next.js hydration mismatches can occur if impure functions like `Math.random()` are used during the render of idle states.
**Action:** Always pre-calculate and cache expensive canvas objects keyed by bounded data values outside the render loop. Use deterministic constant arrays instead of `Math.random()` for idle state styling to ensure React purity and prevent hydration issues. Ensure canvas drawing loops include bounds checks (e.g., `if (x > canvas.width) break;`) to prevent off-screen processing.
