## 2024-05-18 - Canvas Gradients GC Pressure Optimization
**Learning:** In HTML5 Canvas rendering loops dealing with Web Audio API frequency data, the data is typically populated into a `Uint8Array`, meaning it is strictly bounded to integer values from 0 to 255. Re-creating complex objects like `CanvasGradient` on every frame inside a `requestAnimationFrame` loop creates significant Garbage Collection (GC) pressure.
**Action:** Since the possible values are bounded (0-255), explicitly pre-calculate and cache the corresponding `CanvasGradient` objects outside the animation loop. By mapping the bounded `Uint8Array` values to an array of cached gradients, we completely eliminate this object allocation from the render cycle and reduce GC stuttering, maintaining a stable 60FPS. Always handle zero-height cases (e.g. `Math.max(1, height)`) when pre-calculating to prevent finite coordinate DOMExceptions.
