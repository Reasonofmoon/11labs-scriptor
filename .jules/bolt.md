## 2024-05-24 - HTML5 Canvas Optimization and React Hydration
**Learning:** In HTML5 Canvas rendering loops iterating over Web Audio API data, creating `CanvasGradient` objects per frame causes major performance bottlenecks. Since `Uint8Array` frequency data is bounded from 0-255, these can be pre-calculated and cached. Additionally, `Math.random()` in React render cycles (like idle visualizer states) causes Next.js hydration mismatches. Also, short-circuit breaks (`if (x > canvas.width) break;`) prevent useless off-screen rendering calculations.
**Action:** Always pre-calculate and cache rendering objects for bounded data sets outside the render loop. Avoid `Math.random()` for visual states in React components; use deterministic constant arrays instead. Always add short-circuit bounds checks in large iteration rendering loops.
