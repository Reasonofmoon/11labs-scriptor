## 2023-10-27 - Canvas Rendering Optimization and Hydration Mismatches
**Learning:** In HTML5 Canvas animations driven by React's `requestAnimationFrame` loop, repeatedly creating expensive objects like `LinearGradient` inside the render function (e.g., `ctx.createLinearGradient()`) causes unnecessary CPU overhead and garbage collection. Additionally, using non-deterministic values like `Math.random()` in the initial render tree (e.g., for idle state UI) leads to Next.js hydration mismatches between the server and client.
**Action:** Pre-calculate and cache rendering objects (like gradients) outside the animation loop whenever possible. For the Web Audio API, where frequency data maps to a bounded integer range (0-255), we can create a fixed-size cache array for these objects. Furthermore, replace random UI generation during initial render with deterministic constants or arrays to ensure stable hydration.
