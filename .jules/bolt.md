## 2024-03-24 - Canvas Optimizations
**Learning:** In HTML5 Canvas rendering loops with Web Audio API, creating `CanvasGradient` on every `requestAnimationFrame` causes immense Garbage Collection pressure. The Web Audio API data array `Uint8Array` has a bounded range (0-255), allowing pre-calculation of all 256 possible gradients outside the render loop. Also, drawing off-screen bars (when x > canvas.width) is wasted effort. `Math.random()` in React render cycles for visual states causes Next.js hydration mismatches.
**Action:** Always pre-calculate and cache rendering objects based on bounded inputs outside `requestAnimationFrame`. Short-circuit rendering loops (`break`) when drawing goes off-screen. Replace `Math.random()` with deterministic constant arrays for initial render states.
