## 2024-05-24 - HTML5 Canvas & React Render Optimizations
**Learning:** In React components using `requestAnimationFrame` for HTML5 Canvas, expensive object creations like `CanvasGradient` within the draw loop cause significant overhead. Furthermore, unbounded iterations can draw off-screen, and `Math.random()` during render causes hydration/purity lint errors.
**Action:** Pre-calculate `CanvasGradient` (or similar bounded deterministic mappings, like 0-255 frequency data) outside the render loop. Use bounds checking (`if (x > canvas.width) break;`) to early-exit off-screen drawing. Replace `Math.random()` with deterministic constants (`IDLE_BAR_HEIGHTS`) to satisfy React purity rules. Wrap the entire canvas component in `React.memo` to avoid re-renders triggered by parent state changes.
