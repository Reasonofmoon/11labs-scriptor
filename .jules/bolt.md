## 2025-02-18 - [Optimization] CanvasGradient Pre-calculation and GC Pressure Reduction
**Learning:** In HTML5 Canvas rendering loops iterating over large datasets (e.g., Web Audio API frequency arrays at 60fps), generating `CanvasGradient` objects per frequency bar per frame creates massive Garbage Collection (GC) pressure (e.g., 60fps * 1024 bins = ~61,440 gradients/sec garbage). However, because Web Audio API `Uint8Array` bounded range is strictly 0-255, we can pre-calculate and cache exactly 256 `CanvasGradient` objects outside the render loop. Also, handling zero-height edge cases with `Math.max(1, height)` is crucial to avoid `DOMException: The coordinates provided are not finite.`.
**Action:** Always check if canvas objects (like gradients or patterns) can be pre-calculated outside the `requestAnimationFrame` loop, especially when the input data has a bounded range (like 0-255 for `Uint8Array`). Always handle 0 values in canvas gradient coordinates.
