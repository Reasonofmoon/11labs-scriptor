## 2024-05-20 - Canvas Gradient Object Allocation Bottleneck\n**Learning:** Generating CanvasGradient objects inside a `requestAnimationFrame` loop for every frequency bin (from Web Audio API) causes severe Garbage Collection pressure and frame drops. Web Audio `getByteFrequencyData` returns bounded integers 0-255, meaning all possible gradients can be pre-calculated.\n**Action:** Pre-calculate and cache rendering objects for bounded data sets outside the render loop.
