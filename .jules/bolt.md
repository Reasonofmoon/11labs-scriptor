## 2025-03-09 - Pre-calculating CanvasGradients and removing Math.random() in React
**Learning:** Next.js hydration mismatches can occur when using `Math.random()` to generate styles (like an idle visualizer bar height) during the React render cycle, because the server and client will generate different random numbers. Additionally, Web Audio API frequency data is populated into a `Uint8Array`, strictly returning integer values from 0 to 255. Dynamically creating `CanvasGradient` objects inside `requestAnimationFrame` for every single bar iteration creates heavy Garbage Collection (GC) pressure.
**Action:** Avoid `Math.random()` in React render cycles and instead use deterministic constant arrays. In HTML5 Canvas rendering loops iterating over Web Audio API data, pre-calculate and cache the corresponding rendering objects (like `CanvasGradient`) outside the animation frame loop by taking advantage of the bounded 0-255 integer range of `Uint8Array`. Also, add a short-circuit break condition to stop drawing off-screen elements.
