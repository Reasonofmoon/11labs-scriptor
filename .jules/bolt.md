## 2024-05-24 - CanvasGradient Caching with Web Audio API Bounds
**Learning:** In HTML5 Canvas `requestAnimationFrame` render loops, constantly recreating objects like `CanvasGradient` is expensive and causes high garbage collection overhead. When working with the Web Audio API's `getByteFrequencyData`, the `Uint8Array` guarantees integer values strictly between 0 and 255. This fixed, bounded range is perfect for creating an exact-sized array cache (e.g., `new Array(256)`) to store pre-calculated gradient objects for each possible frequency value, eliminating runtime object creation during the render loop.
**Action:** Next time you implement a canvas-based audio visualizer in React, check the data bounds (0-255 for byte data) and pre-calculate expensive rendering objects into an array cache keyed by the data value outside the loop instead of generating them per frame.
