## 2024-10-26 - Pre-calculating Canvas Gradients in React Animation Loops
**Learning:** In HTML5 Canvas rendering loops iterating over large datasets (like audio frequency arrays), repeatedly creating `CanvasGradient` objects on every frame (e.g., inside `requestAnimationFrame`) causes high memory allocation and Garbage Collection (GC) pressure, leading to frame drops. Additionally, creating gradients with a zero height can throw a `DOMException: The coordinates provided are not finite`.
**Action:** Pre-calculate and cache rendering objects (like gradients) strictly outside the `requestAnimationFrame` callback. For Web Audio API `Uint8Array` data, pre-calculate gradients for all possible bounded values (0-255). Ensure edge-case handling for zero-height gradients (e.g., `Math.max(1, height)`). Also, implement short-circuit break conditions (`if (x > canvas.width) break;`) to avoid unnecessary calculation of off-screen elements.
