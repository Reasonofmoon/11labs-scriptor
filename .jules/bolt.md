## 2024-05-18 - Pre-calculating Canvas Gradients for Audio Visualizer
**Learning:** Calling `ctx.createLinearGradient` inside a `requestAnimationFrame` loop per frequency bin causes massive object allocation and GC pressure. Because Web Audio API returns `Uint8Array` (0-255), we can pre-calculate the gradients. We also need to be careful with zero-height edge cases (`DOMException: The coordinates provided are not finite`) and off-screen rendering. Also, using `Math.random()` inside React renders causes hydration mismatches.
**Action:** Initialize a cache array of 256 pre-calculated CanvasGradients strictly outside the `requestAnimationFrame` callback. Add `Math.max(1, height)` for zero-height protection. Break the loop early if `x > canvas.width`. Replace `Math.random()` in render with a deterministic array.
