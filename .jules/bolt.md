## 2024-10-24 - HTML5 Canvas & Next.js Hydration Patterns
**Learning:** In Next.js, using impure functions like `Math.random()` during component rendering (e.g. for idle states) causes hydration mismatches and violates strict React purity rules. Furthermore, HTML5 Canvas animations in React `useEffect` loops suffer from excessive garbage collection if expensive objects like `LinearGradient` are created inside the `requestAnimationFrame` loop.
**Action:** Replace `Math.random()` with deterministic constant arrays (like `IDLE_BAR_HEIGHTS`) for initial renders to ensure hydration matches. Pre-calculate and cache expensive canvas objects outside the render loop, and optimize drawing loops with off-screen bounds checks (`if (x > canvas.width) break;`) to prevent unnecessary processing.
