## 2024-03-24 - Canvas GC Optimization via Bounded Data Arrays
**Learning:** Web Audio API `frequencyBinCount` populates a `Uint8Array` bounded strictly to integers between 0 and 255. In Canvas rendering loops (like `requestAnimationFrame`), recreating rendering objects like `CanvasGradient` for every bar, on every frame, causes massive object allocation and Garbage Collection (GC) pressure.
**Action:** Pre-calculate and cache all 256 possible gradient objects in an array initialized OUTSIDE the render loop (e.g., inside the outer `useEffect`), using the 0-255 byte value as a direct index. This completely eliminates gradient object allocations during the critical render loop path. Ensure to handle 0-height edge cases (e.g., `Math.max(1, height)`) to avoid finite coordinate DOMExceptions.
