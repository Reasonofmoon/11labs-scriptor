## 2024-05-29 - [Canvas Visualizer Render Cycle Fix & Hydration Error]
**Learning:** Pre-calculating a fixed pool of `CanvasGradient` states by exploiting the bounded 0-255 return type of `analyser.getByteFrequencyData` into a `Uint8Array` prevents astronomical memory allocations during requestAnimationFrame loops. Additionally, `Math.random()` inside Next.js functional components causes hydration purity errors; static array cycling achieves the same idle state safely.
**Action:** Next time working with Web Audio API or HTML5 Canvas rendering in React, immediately extract calculations that have a finite number of deterministic outcomes outside of the render loop. Never use impure random functions inside render; rely on stable constants or `useEffect` for random assignment.
