## 2026-05-25 - Web Audio API Canvas Visualizer Optimization
**Learning:** In HTML5 Canvas rendering loops triggered by `requestAnimationFrame`, methods like `ctx.createLinearGradient` are highly expensive. Since the Web Audio API (`AnalyserNode.getByteFrequencyData`) populates a `Uint8Array`, the values are strictly bounded integers from 0 to 255. Instead of recalculating identical gradients on every frame, they can be cached in a size-256 array based directly on the frequency value. Also learned that `Math.random()` in React render cycles causes hydration mismatches between Server and Client in Next.js.
**Action:** When working with bounded array data (like audio frequencies) in high-frequency rendering loops, always pre-calculate and cache expensive 2D context objects outside the animation frame loop. Replace `Math.random()` with static/deterministic values for visual states (like idle bars) to prevent hydration errors.
