## 2024-05-22 - Optimize Visualizer Canvas Pre-calculation
**Learning:** In React `requestAnimationFrame` loops rendering to a `<canvas>`, pre-calculating state arrays (like `CanvasGradient` corresponding to possible bounded `Uint8Array` Web Audio API values) entirely outside the loop yields major rendering efficiency. Ensure you handle `height: 0` coordinates specifically (e.g., `Math.max(1, height)`) since `createLinearGradient` will throw a `DOMException` for non-finite lengths. Short-circuit breaking out of rendering off-screen canvas elements prevents expensive unobservable `ctx.fillRect` calls.
**Action:** When working with 2D Canvas Audio Visualizers, map all finite color/style calculations out of the rendering frame into a static cache, strictly breaking loops when coordinates exceed `canvas.width`.
