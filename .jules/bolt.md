## 2024-05-19 - Pre-calculating Canvas Gradients in React useEffect
**Learning:** In a `requestAnimationFrame` render loop tied to Web Audio API (`AnalyserNode`), dynamically recreating `CanvasGradient` objects per frequency bin per frame causes excessive CPU overhead and garbage collection. Because frequency values are always integers between 0 and 255 (`Uint8Array`), these gradients can be completely pre-calculated and cached. Additionally, a simple `if (x > canvas.width) break;` short-circuit prevents unnecessary math and rendering for bars that extend past the canvas viewport.
**Action:** When working with Canvas visualizations of bounded datasets, always pre-calculate complex drawing objects (like gradients) into an array cache outside the render loop, and ensure off-screen elements are explicitly skipped.
