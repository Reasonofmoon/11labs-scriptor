## 2024-05-18 - Visualizer Component Animation Loop Optimization
**Learning:** In a tight `requestAnimationFrame` drawing loop like the one used by HTML5 Canvas for the `Visualizer`, doing dynamic calculations or creating new objects repeatedly (like `createLinearGradient` or gradient color stops) can drastically slow down the browser. Furthermore, processing out-of-bounds drawing elements wastes processing time without user benefit.
**Action:** Always pre-calculate finite and bounded combinations outside the animation loop. In the `Visualizer`, since byte frequency values strictly fall in the 0-255 integer range, an array of 256 cached `CanvasGradient` permutations can completely replace per-frame object instantiations. Additionally, looping elements must include boundary checks (`if (x > canvas.width) break;`) to skip rendering unobservable pixels. Use `React.memo` to skip unwanted component re-renders altogether.
