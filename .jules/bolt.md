## 2024-05-19 - Pre-calculating Canvas Gradients for Audio Visualization
**Learning:** In React HTML5 Canvas animations, pre-calculating expensive objects like `LinearGradient` within a cache array (initialized outside the `requestAnimationFrame` callback) drastically reduces rendering overhead. Specifically, since Web Audio API frequency data is bounded (0-255), caching these gradients mapping to fixed height bins saves creating thousands of gradient objects per second. Bounds checking (e.g., `if (x > canvas.width) break;`) prevents unnecessary processing of off-screen bars. Also, `Math.random` should not be used in React render components to avoid hydration mismatches and linting errors. Use deterministic arrays instead.
**Action:** When implementing Canvas animations mapping bounded data (like Audio frequencies), use pre-calculated caches for rendering objects outside the render loop and implement bounds checking. Ensure React components are pure by avoiding `Math.random` during render. Wrap complex but stable render components with `React.memo` and define `displayName` to reduce unnecessary re-renders.
