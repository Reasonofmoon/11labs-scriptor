## 2024-11-20 - Web Audio API Bounded Range Allows for O(1) Pre-calculation
**Learning:** Web Audio API's `getByteFrequencyData` populates a `Uint8Array` strictly with integer values from 0 to 255. In React components that render this data via Canvas API every frame (e.g., `requestAnimationFrame`), recreating rendering context objects (like `CanvasGradient`) within the loop for every data point causes massive garbage collection (GC) pressure and frame drops. Because the range is strictly bounded to 256 possible values, we can pre-calculate all possible `CanvasGradient` objects once per dimension change instead of up to 1024 times per frame.
**Action:** Always pre-calculate and cache rendering objects into a lookup array (e.g., indexed 0-255) when working with Web Audio API frequency data to shift time complexity from O(n) per frame to O(1) array lookups, and ensure the cache is instantiated outside the `requestAnimationFrame` loop.
