## 2024-05-24 - [Pre-calculating Canvas Gradients in Web Audio API Visualizer]
**Learning:** Web Audio API frequency data is exposed as a `Uint8Array`, strictly binding values between 0 and 255. In a high-frequency Canvas animation loop (`requestAnimationFrame` at ~60fps), generating a new `CanvasGradient` object on every frame for every frequency bin (e.g., 256 bins * 60 fps = 15,360 objects/sec) causes significant object allocations and subsequent Garbage Collection (GC) pauses, stalling the main thread.
**Action:** Since the input domain is fixed (0-255), pre-calculate the 256 possible `CanvasGradient` objects outside the animation loop (e.g., during `useEffect` initialization) and store them in an array cache (`gradientCache`). Inside the render loop, perform a simple array lookup (`gradientCache[val]`) instead of instantiating new objects. This drastically reduces GC pressure and ensures smooth 60fps rendering. Ensure edge cases like 0 height are handled with `Math.max(1, height)` during pre-calculation to avoid infinite coordinate exceptions in `createLinearGradient`.
