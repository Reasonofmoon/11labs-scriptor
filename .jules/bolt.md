
## 2024-05-18 - [Web Audio API & Canvas Optimization]
**Learning:** In HTML5 Canvas rendering loops iterating over Web Audio API data (like `AnalyserNode` frequency arrays), Web Audio API frequency data is populated into a `Uint8Array`, which strictly returns integer values bounded between 0 and 255. In unoptimized code, continuously creating complex objects like `CanvasGradient` for every element of a large array (e.g., length 1024) inside a `requestAnimationFrame` loop (running at 60 FPS) results in massive Garbage Collection (GC) pressure, allocating over 60,000 objects per second. Furthermore, when creating `createLinearGradient`, zero-height edges cases must be handled (e.g. `Math.max(1, height)`) to avoid `DOMException: The coordinates provided are not finite.`.
**Action:** Exploit the strictly bounded 0-255 range of the `Uint8Array` to pre-calculate and cache the `CanvasGradient` objects strictly *outside* the `requestAnimationFrame` loop. Replace the object creation inside the loop with a simple constant-time cache array lookup (`gradientCache[dataArray[i]]`). Always handle potential zero-values to avoid exceptions in drawing APIs. Ensure the cache initialization is genuinely outside the loop and not repeatedly executed.
