## 2024-06-11 - Visualizer Canvas Optimization
**Learning:** Web Audio API frequency data arrays (Uint8Array) are bounded (0-255). We can map these integer values to pre-calculated canvas LinearGradient objects outside the render loop, drastically reducing garbage collection. Additionally, `Math.random` should not be used in idle state renders to prevent Next.js hydration mismatches. Adding bounds checks when iterating through canvas drawing commands prevents unnecessary processing of off-screen elements.
**Action:** When working with canvas animations, cache expensive objects like LinearGradients based on bounded input values. Avoid `Math.random` in React renders unless properly handled. Add off-screen bounds checking `if (x > canvas.width) break;` inside canvas drawing loops. Wrap components in React.memo when parent updates frequently trigger unnecessary re-renders.
