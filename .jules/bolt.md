## 2024-05-24 - Pre-calculating Canvas Gradients in Web Audio Visualizer
**Learning:** For HTML5 Canvas animations in a React `useEffect`, recreating expensive objects like `LinearGradient` on every `requestAnimationFrame` using continuous frequency data can severely degrade rendering performance. Because Web Audio API populates a `Uint8Array` with bounded integers from 0 to 255, we can exactly pre-calculate and cache all 256 possible `CanvasGradient` objects keyed by those frequency values strictly outside the animation loop, turning an expensive instantiation into an O(1) array lookup per bar per frame.
**Action:** When working with Canvas drawing loops consuming Web Audio `Uint8Array` frequency data, establish a local cache array of rendering objects (e.g., gradients or colors) prior to the `requestAnimationFrame` loop, and use the integer frequency values to index into that cache.
