## 2024-03-24 - [Web Audio Canvas Rendering Optimization]
**Learning:** In Web Audio API visualizations, `analyser.getByteFrequencyData()` populates an array with integers from 0 to 255. Recreating objects like `CanvasGradient` dynamically inside the `requestAnimationFrame` loop creates immense Garbage Collection (GC) pressure, leading to frame drops.
**Action:** Pre-calculate and cache the 256 possible `CanvasGradient` variations in an array strictly outside the rendering loop. Inside the loop, simply index into this cache array `cache[dataArray[i]]`. Additionally, add a short-circuit condition `if (x > canvas.width) break;` inside the rendering loop to avoid unnecessary calculations and rendering of off-screen elements. Avoid using `Math.random()` inside React render cycles as it causes Next.js hydration mismatches; replace with deterministic arrays.
