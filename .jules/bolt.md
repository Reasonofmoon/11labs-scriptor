## 2024-05-14 - Pre-calculating Canvas Gradients
**Learning:** In highly animated React components using HTML5 Canvas (`requestAnimationFrame`), creating objects like `CanvasGradient` or parsing colors on every frame within a loop (e.g., iterating through audio frequency bins) causes severe Garbage Collection (GC) pauses and drops the framerate significantly. Since frequency data from an `AnalyserNode` (`Uint8Array`) has a fixed range of 0-255, we can pre-calculate all 256 possible visual states (like gradients) outside the animation loop.
**Action:** When working with Canvas animation loops, always look for expensive object creations (`createLinearGradient`, `createRadialGradient`, complex string parsing) inside the `requestAnimationFrame` and move them to a pre-calculated cache map or array keyed by the incoming data value.
