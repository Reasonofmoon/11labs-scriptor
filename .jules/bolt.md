## 2024-05-18 - Canvas Gradient Pre-calculation\n**Learning:** Instantiating `CanvasGradient` objects inside a `requestAnimationFrame` loop per frequency bin causes significant unnecessary garbage collection and performance degradation on the main thread, especially when frequency values are strictly bounded (0-255).\n**Action:** Pre-calculate and cache Canvas styling objects (like LinearGradients) based on the bounded 0-255 Web Audio API frequency data array strictly outside the `requestAnimationFrame` callback.
