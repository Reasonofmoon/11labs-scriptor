## 2025-02-15 - Canvas Optimization with Web Audio API Bounded Arrays
**Learning:** Web Audio API's AnalyserNode `getByteFrequencyData` populates a `Uint8Array` strictly returning integer values from 0 to 255. In React HTML5 Canvas animations, instead of recreating expensive objects (like LinearGradient) inside the `requestAnimationFrame` render loop ~4000 times a second, we can perfectly pre-calculate and cache exactly 256 gradient objects outside the loop using an array cache keyed by the frequency integers.
**Action:** Always verify the value bounds of incoming data in render loops. If the range is small and bounded (e.g. 0-255), heavily prefer pre-calculating and caching objects before the animation loop begins. Ensure cache arrays are initialized strictly outside the `requestAnimationFrame` callback.
